Nihilist Cipher

Combine a keyed Polybius square with a repeating additive keyword to produce number ciphertext.

OVERVIEW

What it is

The Nihilist cipher is associated with hand-cipher systems used by Russian revolutionary groups in the late nineteenth century. Despite the dramatic name, the important thing for learning the cipher is its structure: it combines a substitution system with numerical addition.

Unlike a Caesar or Aristocrat cipher, its ciphertext is normally a series of numbers rather than letters. Those numbers are produced in two stages. Understanding those two stages separately makes the cipher much easier to understand.

The first stage is a Polybius square. The second stage is a repeating numerical key. If you understand both pieces individually, the full Nihilist cipher is mostly just addition.

A numerical cipher built in layers. First, letters are converted into coordinates using a 5×5 letter grid called a Polybius square. Then numbers from a repeating keyword are added to those coordinates.
MECHANICS

How it works

Start with a 5×5 grid. Because 25 spaces are available but the English alphabet has 26 letters, I and J are commonly combined into one position. Every square in the grid receives a two-digit coordinate. The first digit tells you the row and the second digit tells you the column.

For example, the top-left square has coordinate 11. The square immediately to its right is 12. The first square in the second row is 21. Therefore a coordinate such as 43 means row 4, column 3.

A keyed Polybius square does not simply place the alphabet into the grid from A onward. Instead, it begins with the unique letters of a keyword. If the keyword is CIPHER, we first write C, I, P, H, E, R while ignoring repeated letters. Then we fill the remaining empty cells with unused letters of the alphabet.

That gives every plaintext letter a numerical coordinate. If H happens to occupy row 1, column 4, then H becomes 14. If E occupies row 1, column 5, E becomes 15.

Now introduce a second keyword called the additive keyword. Suppose the additive keyword is SECRET. Repeat SECRET underneath the plaintext until every plaintext letter has a key letter.

The key letters are converted into coordinates using the exact same Polybius square. Then, position by position, add the plaintext coordinate and key coordinate together. The sum becomes the ciphertext number.

So conceptually the cipher is: PLAINTEXT LETTER → POLYBIUS NUMBER, KEYWORD LETTER → POLYBIUS NUMBER, then PLAINTEXT NUMBER + KEY NUMBER = CIPHERTEXT NUMBER.

Build or encrypt an example

1

Build the 5×5 Polybius square. Write the square keyword first, removing repeated letters, and then fill remaining cells with unused alphabet letters.

2

Label the rows and columns 1 through 5. Every letter now has a two-digit coordinate such as 11, 24, or 53.

3

Write the plaintext. Convert each plaintext letter into its Polybius coordinate.

4

Write the additive keyword repeatedly underneath the plaintext until it reaches the same number of letters.

5

Convert every additive-keyword letter into a coordinate using the SAME Polybius square.

6

Add each plaintext coordinate to the key coordinate directly beneath it.

7

Write those sums as the ciphertext. This is why Nihilist ciphertext often contains numbers such as 57, 72, or 84 instead of ordinary 11–55 Polybius coordinates.

CRYPTANALYSIS

How to solve it

To decrypt a Nihilist cipher when both keywords are known, reverse the process. The final encryption operation was addition, so the first decryption operation is subtraction.

The important idea is that ciphertext numbers themselves are not direct Polybius coordinates. You must first remove the additive-key value. Only then do you get a coordinate that can be looked up in the square.

Suppose one ciphertext value is 57 and the corresponding repeated-key letter has Polybius value 23. Subtract 23 from 57. The result is 34. You then look at row 3, column 4 of the Polybius square to recover the plaintext letter.

1

Rebuild the exact keyed Polybius square used for encryption.

2

Repeat the additive keyword until it lines up with every ciphertext number.

3

Convert each additive-keyword letter into its Polybius coordinate.

4

Subtract each key coordinate from the ciphertext number above it.

5

The result should be a valid coordinate whose two digits are both between 1 and 5.

6

Look up that coordinate in the Polybius square.

7

Repeat for every number to reconstruct the plaintext.

COMMON MISTAKES

What to watch for

Trying to look up ciphertext numbers such as 57 directly in the Polybius square. A 5×5 Polybius coordinate can only contain row and column digits from 1 through 5.
Using a normal alphabetical Polybius square when the puzzle specifies a keyed square.
Using one square for the plaintext and another for the additive keyword. Both must use the same square.
Adding the digits separately. If one coordinate is 24 and another is 31, calculate 24 + 31 = 55. Do not calculate 2+3 and 4+1 as separate operations.
Forgetting the I/J convention when building a 5×5 alphabet.
Failing to repeat the additive keyword correctly across the entire message.
