Baconian Cipher

Turn letters into five-symbol patterns and learn to recognize disguised A/B classes.

OVERVIEW

What it is

Francis Bacon described a biliteral cipher in the early seventeenth century. Its central idea was that two distinguishable forms could encode a sequence of binary-like choices.

Modern puzzle versions commonly show the two forms directly as A and B. Historical and puzzle conventions can differ in how the alphabet is handled, so a solver should always check the specific alphabet or table supplied with a problem.

An encoding system that represents letters using groups made from only two different symbols.
MECHANICS

How it works

Each plaintext letter corresponds to a five-position pattern built from two symbols, normally A and B.

Five binary choices produce enough combinations to represent an alphabet. The Daily Cipher currently uses a straightforward 26-letter teaching table.

CRYPTANALYSIS

How to solve it

Baconian problems become straightforward once the stream is divided into correct groups of five.

The larger challenge in disguised forms is recognizing which two visual features represent the two binary states.

1

Identify the two distinct symbol types.

2

Translate them consistently to A and B.

3

Divide the result into groups of five.

4

Use the supplied Baconian alphabet to convert each group to a letter.

COMMON MISTAKES

What to watch for

Losing track of five-symbol group boundaries.
Switching which visual feature represents A and which represents B halfway through.
Assuming every Baconian variant uses exactly the same historical alphabet.
