Complete Columnar Cipher

Write plaintext into a complete rectangle and read columns in key order.

OVERVIEW

What it is

Columnar transposition belongs to a broad historical family of route and transposition systems. Rather than concealing letter identity, these methods conceal the original order of the letters.

The complete form fills a rectangular grid completely, often using padding when necessary. The key determines the order in which columns are extracted.

A transposition system that places plaintext in a rectangle and reads the columns in a key-controlled order.
MECHANICS

How it works

Write the plaintext row by row beneath numbered columns.

Read the columns according to the numeric key order rather than their physical left-to-right order.

Build or encrypt an example

1

Choose the number of columns and a permutation key such as 3-1-4-2.

2

Write plaintext row by row into the rectangle.

3

Pad the last row if the complete form requires it.

4

Find the column labeled 1 and read downward, then column 2, continuing through the key.

CRYPTANALYSIS

How to solve it

If the key is known, split the ciphertext into equal column lengths and restore them to their original physical positions.

Unknown-key solving requires testing column arrangements and looking for language structure across reconstructed rows.

1

Determine the number of rows from the message length and column count.

2

Split the ciphertext into one section per column.

3

Place each section beneath the correct key label.

4

Read across the rows to recover the plaintext.

COMMON MISTAKES

What to watch for

Confusing a column's physical position with its numeric read order.
Reading rows during encryption instead of columns.
Forgetting padding characters in a complete rectangle.
