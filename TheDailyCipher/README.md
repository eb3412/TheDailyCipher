# The Daily Cipher

The Daily Cipher is an educational cryptography platform designed to help users learn, practice, and compete in classical cryptography.

## Features

- Daily cipher challenges
- Multiple difficulty levels
- Cipher encyclopedia
- Interactive visualizers
- Practice generator
- Statistics and streaks
- Future global leaderboard
- Future competitions

## Project Structure

- `index.html` — main Daily Cipher page
- `learn/` — educational cipher pages
- `practice/` — practice tools
- `visualizers/` — interactive cipher demonstrations
- `data/` — puzzle and encyclopedia data
- `js/` — application logic
- `css/` — styling

## Development

The project currently uses HTML, CSS, JavaScript, and JSON.

A local development server such as VS Code Live Server should be used because the application loads JSON files with JavaScript `fetch()`.
